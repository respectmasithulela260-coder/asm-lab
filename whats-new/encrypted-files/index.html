Files

Project files are encrypted

ASM Lab files are now always saved encrypted. Give a password when you save and the file opens only for people who know it; the password is not stored anywhere, so keep it safe. Leave it empty and the file is still encrypted and opens in ASM Lab without asking.

Older files still open as before. AI tools connected to ASM Lab can read an encrypted project only while it is open in ASM Lab.

What you get

  • Encrypted on every save
  • Optional password
  • Old files still open
