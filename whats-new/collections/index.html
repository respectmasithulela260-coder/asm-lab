Network

Collections and links

A collection is a group of tunnels you can work on separately, such as one level or one section. Nodes on different collections can be linked, and a linked node moves with its partner.

The solve names any collection it left out and offers a Link them button. Scripts can create and select collections and link nodes between them.

What you get

  • One link distance (0.5 m) everywhere
  • Merge keeps links
  • The solve solves linked collections together
