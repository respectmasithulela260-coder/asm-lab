Scripting

Script your mine in JavaScript

Open the Script panel to build and change a network with code. Scripts can create nodes and airways, add ducts, fans and size changes, set heat and boundaries, and run the solve.

Templates are grouped by category, the editor shows line numbers and syntax colours, and heavy work runs in the background so the window stays responsive.

const a = node(0, 0);
const b = node(300, 0);
airway(a, b, { area: 20 });
await solve();
console.log(result());

What you get

  • Nodes, airways, ducts, fans, heat and boundaries
  • await solve() with result()
  • Write results to CSV
  • File access on the desktop app, asked first
