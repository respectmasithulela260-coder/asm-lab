File handling

An ASM Lab project is saved as an .asmlab file. It holds everything: the collections (levels), airways, nodes, devices, heat sources, ducts, fire studies, Studio shots and settings. The file is encrypted; you can add a password when you save.

CommandWhat it does
File > New (Ctrl+N)Starts an empty project.
File > Open (Ctrl+O)Opens an .asmlab project or a .json network file.
File > ImportBrings in DXF drawings, 3D models (OBJ, STL, glTF), Datamine .dm files and other formats.
File > Import spreadsheetReads nodes and airways from an XLSX or CSV file, with a step to match its columns.
File > Save (Ctrl+S)Saves the project as an .asmlab file.
File > Save As (Ctrl+Shift+S)Saves under a new name or location.
File > ExportJSON, DXF, glTF (.glb), Datamine .dm, CSV tables and a PNG screenshot.
File > BackupsThe last versions of the project, kept automatically; open one to go back.
File > Recover AutosaveBrings back unsaved work after the program closed unexpectedly.
File > RevertDiscards the changes since the last save.
File > Clean UpRemoves unused nodes, airways of zero length and empty levels.

Task: Save a project

  1. Choose File > Save, or press Ctrl+S.
  2. The first time, choose a folder and type a file name. The file is saved with the extension .asmlab.
    Note: You can set a password when you save. Keep it safe: a file cannot be opened without its password.

Task: Open a project

  1. Choose File > Open, or press Ctrl+O.
  2. Select an .asmlab file and click Open. The project replaces the one on screen; the one you had is kept in File > Backups.

Task: Import a DXF drawing as tunnels

  1. Choose File > Import and select the DXF file.
    Note: ASM Lab reads ASCII DXF files. A binary DXF or a DWG file must first be saved as ASCII DXF in your CAD program.
  2. In the Outliner, choose whether the drawing is used as tunnels (it becomes a network of airways) or kept as a reference drawing.
  3. Check the network with Home > Simulate > Check and fix any gaps it reports before you solve.

Task: Recover work after a crash

  1. Start ASM Lab again.
  2. Choose File > Recover Autosave, or click Continue where I left off on the start screen.
